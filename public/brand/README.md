# Nestwell brand assets

| File | Use |
|---|---|
| `nestwell-logo.png` | Full wordmark, transparent background. Use on light backgrounds (home, login). |
| `nest-mark.png` | Round copper nest, transparent corners. Used as the app header mark. |
| `nestwell-logo-original.png`, `nestwell-nest-original.png` | Untouched originals as supplied. |
| `../icon-192.png`, `../icon-512.png` | App and home screen icons (full-bleed copper square; phones round the corners). |
| `../icon-maskable-512.png` | Android adaptive icon with safe-zone padding. |
| `../apple-touch-icon.png` | iPhone and iPad "Add to Home Screen" icon (180×180). |

The icons were made from a 272px source. If you have a larger or vector (SVG/AI) version of the nest, drop it here and regenerate the icons for extra-sharp home screen icons.
